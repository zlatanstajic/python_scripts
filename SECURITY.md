# Security Policy

## Supported versions

Security fixes are considered for the latest version on `master`. Older
releases are not maintained separately.

## Reporting a vulnerability

Use **Report a vulnerability** on the repository's GitHub **Security** tab
when private vulnerability reporting is available. Include the affected
command, steps to reproduce, and the potential impact. Do not include real
credentials or private data in the report.

If that option is unavailable, open a GitHub issue asking the maintainers for
a private contact method. Do not post vulnerability details in the issue.

The maintainers will review the report and coordinate a fix and disclosure
with the reporter as appropriate.
