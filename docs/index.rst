Python Scripts
==============

This project provides two Python command-line utilities: a Markdown-to-PDF CV
generator and a Playwright-based website screenshot tool.

Utilities
---------

* :mod:`scripts.cv_generator` renders a single-page PDF CV from Markdown.
* :mod:`scripts.screenshot` captures 1600x900 viewport JPEGs of websites.
